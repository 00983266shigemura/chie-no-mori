# ちえの もり

小学校受験の ペーパーの もんだいを、年長の子が iPad で あそびながら といていく アプリ。
ページ1枚（index.html）で動き、通信も外部の部品も使わない。問題は 全部 その場で作る（同じ形が また出ることはある）。

## もんだいの かたち（7つ）

| かたち | なに | もとになった 過去問の型 |
|---|---|---|
| てんせん | 左の おてほんと 同じ形になるよう、右の点を順にタップして線を引く | 点図形の模写 |
| かがみ | 鏡（左右）・みずうみ（上下）に映した形を 4枚から選ぶ | 鏡図形・水面 |
| かぞえる | ばらばらに並んだ形の中から 1種類だけ数える | 選んで数える |
| シーソー | 2〜3台のシーソーから いちばん重い／軽い／2番目を選ぶ | 重さくらべ |
| トンネル | お約束（例）から 増減を読み取り、通ったあとの数を答える | ブラックボックス |
| おなじ かたち | 3×3の ますの しるしが同じ（回した）ものを選ぶ | 同図形・回転同図形 |
| かさねる | 2〜3枚の線を重ねた形を選ぶ | 重ね図形 |

- まぜまぜ＝7つから つぎつぎ出る（本番の流れに近い）
- レベルは自動で上下＝5問中4問を1回で正解すると上へ、2問以下なら下へ（おとなのひと の画面で見える）
- せいかいで はっぱ（1回目2枚・2回目1枚・3問連続で＋1）。24枚で いきものが1匹 ずかんへ
- もんだい文は 端末の こえで よみあげ（iPad の設定で日本語の声が無ければ 文字だけ）
- 「おとなのひと」を ながおし＝なまえ・1まわりの問題数・おと・よみあげ・記録の消去

## 動く端末

2012年の iPad（iOS 10.3.3・Safari 10.1 相当）で動く書き方だけで書いてある。
新しい書き方・絵文字は使わない（`tools/check_es5.py`・`tools/check_chars.py` が止める）。

## つくりかた

- 直すのは `src/` の中だけ（`app.js`＝しくみ／`ui.js`＝画面／`template.html`＝入れもの）
- `python3 tools/build_app.py` が `index.html` と `offline.appcache` を組み立てる
- 直したら `src/app.js` の `APP_VERSION` と `version.txt` を同じ数字で +1 する
- `zsh tools/check_all.zsh` で検査（組み立て・古い書き方・字の在庫・アイコン・ブラウザでの自己点検・iPad よこおきの1画面）
- ホーム画面の絵は `python3 tools/make_icon.py` だけが作る
- 公開は `zsh push.zsh`（しげが実行）
